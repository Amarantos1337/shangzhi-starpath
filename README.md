# 商职星途 · 九秩校庆

面向在校生、校友与作品浏览者的校庆专题，以“回望校史—走近校友—传承成长—行动献礼”串联内容。保留面向计算机与信息类零基础新生的完整学习指南。无需安装依赖，直接打开 `project/index.html` 即可使用。

## 升学 AI 计划

在 `#/paths/education` 点击“使用这条路线”，填写学历、专业、年级、基础和地区，开始日期默认当天。学历只有专科、本科；专科可选择大一至大三，本科可选择大一至大四，切换学历时清除不适用年级。“目标院校与专业”选填，占位提示为“请输入心仪院校和专业”；留空时根据专业、年级和地区发现候选，逐校核验三所院校，预览和保存页单独展示推荐理由及院校官网/研招网出处。推荐是候选方向，不代表用户已选定院校或保证录取。不再收集计划周数、每周时间和限制条件。提交的个人情况会发送给 DeepSeek；不收集姓名、联系方式，也不把完整表单存入计划备份。

“目标院校与专业”也支持“济南本地一本院校”等筛选条件。代码将明确的城市条件优先于表单中较宽泛的目标地区；推荐必须提供实际专业培养校区所在地及已检索的官方出处，城市或省份不匹配时触发修复，不能用外地院校对标或凑数。一本/二本要求须提供历史招生口径的官方匹配依据，不将其直接等同于985、211或所有本科院校。提示词先发现本地候选，再分别核对院校的招生目录、培养校区和层次依据；当前流程从候选中逐校核验三所不同院校，不能用筛选说明代替名单。一本/二本可按批次取消前的官方历史招生记录作为院校层次参考，注明年度、省份和范围；不要求未来硕士招生目录存在一本/二本批次，未来年度科目、资格等另列待核实。检索最多18次，优先发现5–8所候选，再按候选顺序核验前三所。所在地、条件依据、筛选要求及不足说明随计划保存并支持备份；旧备份的这些新增字段可省略。

计划标题、目标、摘要、任务与推荐理由均要求自然中文，出现内部变量名、字段赋值或代码片段时触发一次自动修复。旧计划的资料摘要和推荐文案在显示时将已知内部字段转换为中文，保留原始存储数据，无法转换的内容提示重新生成。新生成摘要中的具体年份、日期和事实仍需保留。

计划在请求前按年级确定目标初试年份，AI 返回的正式日期必须与该年份一致。按9月开始的学年和四年制本科推算，大四上学期参加初试：2026年秋的大一、大二、大三、大四分别对应2029、2028、2027、2026年初试（招生入学年度再加一年），春季仍属于上一年开始的学年。如果开始日期已经晚于当学年考试季，则顺延一个考试年度。年级按所填开始日期所在学年理解。专科暂按三年专科衔接两年本科估算，明确标注路径、毕业时间和报考资格待核实，不默认具备应届本科资格。

目标年度考试日期已公布时，AI 引用实际搜索返回的教育部、教育部教育考试院或研招网通知，计划至初试前一天；尚未公布时，使用目标年份12月第三个周六作为**暂定学习规划参考**，截止前一天，预览明确显示“考试季暂定安排，初试日期未公布”。正式 `examDate`、`examSourceUrl` 留空，不将计算日期或往年通知冒充该年度官方日期；公告发布后可修改日期或重新生成。长线任务必须覆盖整个期限的前、中、后期，低年级打基础，高年级强化冲刺。旧计划不会自动改写，先前生成期限不符的计划需重新生成。

生成时表单收起，展示“AI 搜索资料”“AI 思考并生成计划”进度；未指定院校时还显示与检索并行的“AI 设计学习行动”，以及实时“已用时x分钟x秒”。等待期间隐藏“使用原始模板”，失败后恢复表单与模板入口。完成后在预览显示“用时x分钟x秒”，保存和备份后仍保留总用时。取消、失败或切页会清理计时器，失败时恢复已填写表单。

`project/js/ai-config.js` 集中配置 API Key、接口、模型 `deepseek-flash`、检索思考强度 `high` 和300秒总超时。学习行动草稿、最终整合、指定院校的计划生成及一次最终修复使用 `low`。更换密钥只需修改此配置，维护时不要输出密钥，仓库保持私有。

使用 DeepSeek Anthropic 兼容接口的 `web_search_20250305` 工具，指定学校时至少6次、未指定具体学校时至少15次、最多18次搜索。指定学校时六项检索并行；按条件推荐时，政策、资格与候选发现并行，随后逐校核验三所院校，同时生成16项学习行动草稿。所有请求共用最多8个并发槽位，搜索预算跨任务累计，各检索任务独立续查、最多20轮；草稿不计搜索次数。按条件推荐时，检索和草稿完成后由程序合并院校信息，AI 只整合摘要及需要修改的行动；指定学校时，在六项检索完成后生成16项学习行动。结果均在校验后统一预览。提示词要求分开核对国家政策、学历资格、院校招生简章、专业目录和考试科目，并记录资料年度与发布日期。工具限定 `gov.cn`、`edu.cn`、`chsi.com.cn` 及山东省教育招生考试院 `sdzk.cn`；本地再次校验域名，排除商业网页和伪装官方域名的链接。最终生成或整合仅使用带实际检索官方出处的资料，引用必须属于本轮已检索的官方来源，或带核验日期的官方历史参考资料。济南历史一本参考收录济南大学、山东师范大学和山东财经大学2016年官方招生记录（2026-10-07核验），注明适用省份与混合批次范围；此资料只证明历史层次，专业与校区仍由本轮检索核对。无官方结果或可核对摘要时明确报错，不把模型记忆标为联网资料。域名过滤不代替原文核实，提示词同时排除论坛、广告、转载及非官方预测。格式校验失败最多修复一次。API 错误、断网、超时均保留表单，允许重试或使用原始模板。关闭弹窗或切页会取消请求；预览和取消不保存，确认保存创建独立计划。

任务和日期为 AI 学习建议，资料摘要未经人工核实；报名资格、科目与日期以对应年度官方通知为准。计划保留参考标题、链接、模型与检索生成时间，现有编辑、进度和备份功能继续使用。来源标题移除搜索结果中的 HTML 碎片，文本继续转义；AI 弹窗采用网站金色圆角滚动条，悬停为主题红色。`store.createAiPlan(details)` 接收 `{ title, goal, tasks: [{ title, stage, dueDate }], generation: { model, generatedAt, summary, sources: [{ title, url }], durationSeconds?, period?, recommendations? } }`，校验后一次保存，自动生成编号。`period` 包含开始、截止、正式初试日期及出处；新记录另含 `targetExamYear`、`dateStatus`（official/estimated）和 `planningBasis`，`recommendations` 为 `{ name, reason, sourceUrl }` 数组。v1 备份的新增字段均可选，旧备份仍兼容，新备份保留暂定日期状态与推荐出处。
