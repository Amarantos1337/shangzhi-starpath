# 开源组件、服务与素材说明

## 网站运行组件

网站没有第三方前端框架、CDN、外部字体或npm运行依赖。HTML/CSS/JavaScript、SVG组件与localStorage使用浏览器原生能力。
DeepSeek是升学AI功能使用的在线服务，不是本项目开源组件；不能把它描述成华为云码道提供的运行接口。
Python实践案例只使用标准库，随包保留起始文件、参考成品和说明。

## 素材与资料来源

校徽及校友照片沿用原项目素材和注明的来源，不代表素材已获得开源许可；保留学校及教师主页的来源、日期和使用说明。
石振邦条目使用返校活动现场照片，页面已说明并非本人独照。
校史、校友经历和照片来源详见 [来源索引](来源索引.md)、源码data.js和页面资料链接。平台分析、成长模板与人物公开经历分别呈现。
校庆纪念视觉和教学案例沿用本项目已有内容；本次介绍及视频页面截图来自V3实际运行。
