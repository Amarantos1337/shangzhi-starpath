# 华为云码道应用总结

## 核心开发与交付应用

商职星途网站核心开发由本人亲手使用华为云码道完成，码道作为核心AI编程工具参与网站核心功能实现。

2026年10月10日，在网站核心功能已经完成的基础上，通过CodeArts Agent IDE继续补充参赛交付材料：分析升学AI的检索、校验、取消和保存逻辑；生成提交包独立运行的检查脚本；根据实际检查反馈修订脚本并定位文档路径问题。
交付补充Prompt要求不读取AI配置或密钥、不输出请求头，不改网站业务源码。补充代码生成后由协作助手审查并实际运行检查。

## 工具角色

- 华为云码道：本人亲手操作的网站核心开发工具；本次交付补充阶段继续承担工程分析、检查工具代码生成及修订。
- 网站中的DeepSeek：用户使用升学规划时的检索与计划生成服务。
- Codex：组织交付材料、录制验证、制作作品介绍PowerPoint、男声视频及最终验收。

码道用于开发，DeepSeek用于网站运行时的升学规划；Codex用于交付协助。码道无需作为网站运行依赖安装。
