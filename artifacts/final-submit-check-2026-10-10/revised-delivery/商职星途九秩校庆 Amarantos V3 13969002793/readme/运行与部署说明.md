# 运行与部署说明

## 环境依赖与一键启动

网站采用原生 HTML、CSS、JavaScript，所有样式、人物照片与教学材料均在本包。没有 npm 安装、打包构建、数据库或后台服务。

| 使用方式 | 所需环境 | 是否联网 |
| --- | --- | --- |
| 直接打开网页 | 支持 JavaScript 的现代浏览器，推荐 Edge/Chrome | 基础功能不需要 |
| HTTP 本地预览 | Python 3.9+；Windows 可使用 python 或 py -3 | 不需要 |
| Python学习统计案例 | Python 3.9+及标准库 | 运行案例不需要 |
| 交付检查脚本 | Node.js 22+，推荐24 LTS；仅内置模块 | 不需要 |
| 升学AI生成 | 浏览器及可访问的现有DeepSeek服务 | 需要 |

双击 [一键启动.cmd](一键启动.cmd) 即可直接打开网站。网站运行无需安装任何软件包，所以没有额外依赖安装步骤。
双击 [环境检查.cmd](环境检查.cmd) 查看可选Python/Node是否可用；双击 [HTTP预览.cmd](HTTP预览.cmd) 使用Python启动静态服务。脚本不下载软件，不修改系统设置。

## 手动运行

在提交包根目录执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory project
```

Windows若只有Python启动器，可改成：

```powershell
py -3 -m http.server 8765 --bind 127.0.0.1 --directory project
```

Linux/macOS使用 `python3` 替代 `python`。打开 http://127.0.0.1:8765/，终端保持运行，Ctrl+C停止。
端口被占用时改为8766并同步修改浏览器地址。本包不需要开发仓库的tools/或tests/。

## 本包检查入口

在提交包根目录运行：

```powershell
node readme/check-submission.js
```

检查目录、关键交付文件、JavaScript语法及本地链接；成功返回0，发现问题返回1。不会请求AI或输出AI配置内容。
实际浏览器验收结果见 [验收记录](验收记录.md)。自动检查不替代视频和演示文稿的人工视觉检查。

## 静态部署

把project目录的全部文件上传到支持静态网页的服务器，让index.html位于站点入口。保留assets/css/js/materials/docs等相对路径。
不需要配置服务端路由：应用采用Hash路由，网址中的#/由浏览器处理。若部署到子路径，仍需完整保持project内部目录结构。
本次没有发布到公网，也没有提交至比赛平台。

## 数据与AI使用

收藏和计划保存在localStorage中。不同浏览器、file地址、域名及端口的存储互相独立；更换地址前先导出JSON备份。
导入先校验，再确认替换；无效文件或取消操作不改变现有记录。最多20份计划、每份100项任务，备份上限32 MiB。
浏览器无法长期存储时，应及时导出备份。

AI入口为成长传承→升学深造→使用这条路线。填写学历、年级、专业、基础、地区和选填院校，检索后预览，再保存到我的成长。
AI生成需要联网，现有配置随本次私有参赛样品保留；维护时不得输出配置密钥。普通检查不消耗API余额。
校史及校友经历来自公开资料，成长模板和AI任务属于建议；正式招生要求和考试日期以对应年度官方通知为准。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 页面空白或图片缺失 | 完整解压，保持相对路径，启用JavaScript |
| Python或Node未安装 | 直接打开index.html仍能体验网站；这些工具仅用于可选预览、实践和检查 |
| 更换浏览器后记录消失 | 在原环境导出，再到新环境导入 |
| AI断网、超时或校验失败 | 查看错误与已找到资料，重新检查输入；原始模板仍可使用 |
| 未来年度初试日期未公布 | 页面显示暂定学习期限，不代表官方考试公告 |
| 导入失败 | 使用本项目完整JSON，核对大小与错误提示，已有数据保留 |
