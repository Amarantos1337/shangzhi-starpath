# 商职星途 · 九秩校庆 V3

面向山东商业职业技术大学办学90周年的学生作品，将校史、真实校友故事、成长实践与个人成长计划连接起来。

网站核心开发由本人亲手使用华为云码道完成。2026年10月10日的交付补充阶段又使用码道进行工程分析、交付检查工具生成与修订；开发过程与本次补充记录见 [码道应用总结](readme/码道应用总结.md)。

## 评审阅读顺序

1. [作品介绍 PowerPoint](ppt/商职星途作品介绍.pptx)：24页可编辑介绍，包含场景、功能流程、实践、架构与码道核心开发及交付应用。
2. [功能演示视频](video/商职星途功能演示.mp4)：三分钟内，中文男声旁白和字幕。
3. [运行与部署说明](readme/运行与部署说明.md)：无需前端安装或构建。
4. [码道证据索引](codearts_proof/证据索引.md)：核心开发归属、本次交付补充操作与现存证据覆盖范围。
5. [验收记录](readme/验收记录.md)：实际检查结果与验收范围。

video目录仅保留功能演示MP4和演示成长备份JSON。视频制作资料放在readme：[录制说明](readme/视频制作资料/录制说明.md)、[旁白稿](readme/视频制作资料/旁白稿.md)、[中文字幕SRT](readme/视频制作资料/中文字幕.srt)。

## 快速体验

直接打开 [project/index.html](project/index.html)，或双击 [一键启动](readme/一键启动.cmd)。
升学AI需要联网，其他本地功能不需要后端。基础功能零依赖；项目没有账号系统。
