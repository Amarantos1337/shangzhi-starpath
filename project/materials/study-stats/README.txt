学习时间统计 · 原创教学示例

输入为虚构的七条学习记录，不是真实学生数据。
需要 Python 3，只用标准库，无需 pip 安装任何包。

环境：从 https://www.python.org/downloads/windows/ 按官方说明安装。
重开 PowerShell，运行 python --version。若使用 py 命令，后续统一替换 python 为 py。

起始练习：在 starter 目录运行 python stats.py；默认只读入记录，累计部分尚未完成。
参考成品：在 reference 目录运行 python stats.py；与 expected.txt 对照。
CSV 始终从脚本所在目录读取，与终端当前目录无关。

手工核算：30 + 45 + 60 + 30 + 45 + 45 + 30 = 285。
Python 30 + 30 + 45 = 105，网页 45 + 45 = 90，数学 60 + 30 = 90。

下一步：复制一份数据后把首条 30 改为 40，预测总计为 295、Python 为 115。
练习完恢复原文件。参考版会对空科目、无效分钟数和错误表头给出错误信息。
时长用于观察安排，不等同于知识掌握程度。项目说明里请同时记录学习成果。
