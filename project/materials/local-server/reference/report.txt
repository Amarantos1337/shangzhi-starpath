本地网站运行与排障 · 参考报告（教学示例）

命令：python -m http.server 8777 --bind 127.0.0.1 --directory site
环境：Python 3，终端当前位于 starter 或 reference，里面有 site 文件夹。

观察一：首页 / 新请求返回 200，正文显示“本地服务练习”。
观察二：/missing.html 返回 404，服务仍然在运行。
练习准备：在自己的副本中将首页链接临时从 about.html 改成 info.html。
问题：修改后的首页“查看说明”指向 /info.html，返回 404。
原因：文件列表中只有 about.html，没有 info.html。
修改：把 index.html 的 href="info.html" 改成 href="about.html"。
验证：点击链接，/about.html 返回 200，正文显示“说明页已找到”。

结束：Ctrl+C 停止自己启动的服务；请求新地址 /after-stop.html?check=1，连接失败。
区别：404 是服务对不存在的资源作出响应；停止服务后没有该服务响应。
缓存可能导致重复首页请求出现 304；查看网络面板中文档请求，不把图标请求当成首页。
