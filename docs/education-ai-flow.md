# 升学规划 AI 流程

```mermaid
flowchart TD
  A[填写学历、年级、专业、基础、地区与目标] --> B[校验表单并推算目标初试年份]
  B --> C{是否指定具体学校？}
  C -->|是| D[围绕指定学校检索]
  C -->|否或仅写筛选条件| E[发现5–8所候选并核对至少3所学校]
  D --> F[联网检索官方政策、招生与专业资料<br/>指定学校至少6次；未指定至少15次，最多18次]
  E --> F
  F --> R{实际搜索次数是否充足？}
  R -->|否| F
  R -->|是| G[过滤非官方来源<br/>保留实际检索网址与带出处的摘要]
  G --> H[结合带核验日期的官方历史资料<br/>按地域、专业和历史一本/二本层次筛选<br/>当前资格与未来年度要求单独说明]
  H --> I[生成中文摘要、院校推荐和4阶段学习任务]
  I --> J{本地校验是否通过？}
  J -->|否| K[将具体错误交给AI修复一次]
  K --> L{修复后通过？}
  L -->|否| M[显示错误并保留表单，不保存无效计划]
  L -->|是| N[预览并允许修改]
  J -->|是| N
  N --> O{用户确认保存？}
  O -->|是| P[保存到我的成长，支持刷新和备份]
  O -->|否| Q[取消，不创建计划]
```

校验要求包括：未指定具体学校时推荐3–5所不同院校；推荐所在地符合用户的城市或省份；历史层次附适用年度、省份及官方依据；所有引用属于本轮实际检索的官方来源或注明核验日期的官方历史参考资料；正文不包含内部变量、代码或 JSON 片段；任务覆盖全部规划学年。数量不足的说明不能代替推荐名单。

一本/二本作为批次取消前的历史招生层次参考，不代表当前硕士招生等级。目标年度尚未公布的资格、科目和日期明确标为待核实或暂定。

实现与完整提示词在 `project/js/ai.js` 的 `generate()` 中；结果校验在 `parsePlan()` 中，保存校验在 `project/js/storage.js` 中。
